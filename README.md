# My-Data-Structures
This is a collection of data structures I made as practice for myself. Code repetition is intentional.

## Vector
A simple Dynamic Array using raw pointers, new, and delete.

## List
A doubly Linked List made with sentinel head and tail to simplify null checks.
In addition to simple functionality like adding and deleting, it has other more complex ones like reverse, remove duplicates, and swap nodes.

## Queue
Three different implementations of queue, using a fixed circular buffer, a linked list, and a dynamic array.

## Table
A simple hash table using string for keys, linear probing, and table doubling.

# Practice

## Text Holder
A simulation of how ctrl+z ctrl+shift+z works using two stacks.

## Line
A queue line that uses tickets and simulates and actual line.
However, its design used polymorphism and virtual functions. This complexity, while unnecessary for this scope of a problem, was added as a practice on OOP abstraction and polymorphism.
